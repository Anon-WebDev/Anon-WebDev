# Luma Wellness Spa Website

Production-ready, single-page business website built with **Next.js App Router**, **TypeScript**, and **Tailwind CSS**.

## Overview

This project provides a high-converting local spa/wellness marketing site with:

- Server Components by default for strong performance.
- A single Client Component (`Header`) only for mobile menu interactivity.
- Section-based page architecture for easy reuse and rebranding.
- Accessible semantic markup and keyboard-friendly interactions.
- SEO metadata, Open Graph, Twitter cards, robots, sitemap, and JSON-LD.
- Centralized editable business content in `lib/site.ts`.

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- `next/image` for optimized images
- `next/font` for typography performance

## How to Customize Content

All core business content is in `lib/site.ts`.

Update this file to rebrand or localize quickly:

- Business name, URL, address, phone, email
- Hero headline and trust badges
- Services (title, description, price, duration)
- About copy and stats
- Benefits list
- Gallery images and alt text
- Testimonials
- FAQs
- Header/Footer navigation links

## Deployment Guide

## Option A: Deploy to Vercel (Recommended)

1. Push this repository to GitHub/GitLab/Bitbucket.
2. Go to [https://vercel.com/new](https://vercel.com/new).
3. Import your repository.
4. Vercel auto-detects Next.js settings.
5. Click **Deploy**.
6. After deployment, add your production domain.
7. Update `siteConfig.url` in `lib/site.ts` to your final canonical URL.
8. Redeploy so metadata/sitemap/robots use the correct domain.

### Vercel Environment Variables

No environment variables are required right now.

If you later add booking APIs, create variables in **Project Settings → Environment Variables**.

## Option B: Deploy to a Node.js Server (Self-hosted)

1. Install dependencies:

```bash
npm install
```

2. Build app:

```bash
npm run build
```

3. Start production server:

```bash
npm run start
```

By default, Next.js listens on port `3000`.

To run on a custom port:

```bash
PORT=8080 npm run start
```

Use a reverse proxy (Nginx/Caddy) and HTTPS in production.

## Option C: Docker Deployment (Example)

You can containerize the app with a multistage Docker build:

```dockerfile
FROM node:20-alpine AS deps
WORKDIR /app
COPY package.json package-lock.json* ./
RUN npm ci

FROM node:20-alpine AS builder
WORKDIR /app
COPY --from=deps /app/node_modules ./node_modules
COPY . .
RUN npm run build

FROM node:20-alpine AS runner
WORKDIR /app
ENV NODE_ENV=production
COPY --from=builder /app/.next ./.next
COPY --from=builder /app/public ./public
COPY --from=builder /app/package.json ./package.json
COPY --from=builder /app/node_modules ./node_modules
EXPOSE 3000
CMD ["npm", "run", "start"]
```

Then run:

```bash
docker build -t luma-spa-site .
docker run -p 3000:3000 luma-spa-site
```

## Troubleshooting

### `npm install` fails with registry/network errors

- Verify internet/proxy/firewall settings.
- Check npm registry config:

```bash
npm config get registry
```

Expected:

```text
https://registry.npmjs.org/
```

### Images not showing

- Confirm files exist in `public/images`.
- Confirm image names match exactly (case-sensitive on Linux).

### Wrong canonical/sitemap domain

- Update `siteConfig.url` in `lib/site.ts`.
- Rebuild/redeploy.
